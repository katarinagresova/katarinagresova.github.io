--- layout: bare permalink: /cv/print/ sitemap: false --- {%- comment -%} The two-page CV, rendered to assets/katarina-gresova-cv.pdf. It is a separate page from /cv/ rather than a print stylesheet over it, because the two documents have genuinely different jobs: the web CV is the complete record and can afford to run long, while a PDF someone opens in a hiring thread has about two pages of their attention and everything after that is noise. It still reads from the same data files, so the two cannot drift. What makes it fit is selection, applied here as rules rather than as a hand-kept copy: * research positions keep a one-line detail, industry roles do not; * software is the `featured: true` set from _data/work.yml, using each entry's `short:` — a clause written for print, not a truncated `blurb:`; * teaching is courses and written material; supervision collapses to a single counted line and the talks list is dropped entirely; * publications are the `selected: true` set.
